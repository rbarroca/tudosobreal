# Link para tudosobrealojamentolocal.pt — Instruções

Adicionar um link do calculadoraal.pt para tudosobrealojamentolocal.pt
para melhorar a autoridade de domínio e acelerar a indexação no Google.

---

## Opção A — Bloco de contexto (mais eficaz para SEO)

Adicionar no fim de uma secção de conteúdo da homepage, antes do footer:

```html
<div>
  <p>
    Ainda a pensar em abrir o seu Alojamento Local? 
    Consulte o <a href="https://tudosobrealojamentolocal.pt">guia de alojamento local em Portugal</a> 
    com tudo o que precisa de saber sobre registo, fiscalidade e legislação.
  </p>
</div>
```

---

## Opção B — Footer (mais simples)

Adicionar na secção de links do footer:

```html
<a href="https://tudosobrealojamentolocal.pt">
  Guia de Alojamento Local em Portugal
</a>
```

---

## Opção C — CTA dentro de um artigo ou secção explicativa

Se o calculadoraal.pt tiver texto explicativo sobre AL, adicionar no contexto:

```html
<p>
  Para saber mais sobre como abrir e gerir um 
  <a href="https://tudosobrealojamentolocal.pt/como-abrir-alojamento-local">
    Alojamento Local em Portugal
  </a>, consulte o nosso guia detalhado.
</p>
```

---

## Notas importantes

- **Texto âncora** — usar sempre palavras descritivas como "guia de alojamento local"
  ou "alojamento local em Portugal". Evitar "clique aqui" ou "saiba mais".
- **Não usar `rel="nofollow"`** — o link deve passar autoridade (dofollow por omissão).
- **Posição** — quanto mais acima na página e dentro de texto corrido, mais valor tem para o Google.
- **Uma vez feito**, submeter a homepage do calculadoraal.pt no Google Search Console
  para o Google reindexar e seguir o novo link rapidamente.
